# Network Studio v2026.11.21

Переносимая сборка Windows x64. Скачайте **network-studio-v2026.11.21-windows-x64.zip**, распакуйте целиком и запустите **launch.cmd**. [Установка](https://github.com/NikitaKonstantinovich/network-studio/blob/v2026.11.21/docs/INSTALL_RU.md) · [Руководство](https://github.com/NikitaKonstantinovich/network-studio/blob/v2026.11.21/docs/USER_GUIDE_RU.md)

- **«Открыть результаты…»** открывает комплект CSV/JSON в отдельном окне. Общий интервал применяется к графикам и журналам. Растр использует весь доступный экспортированный журнал. Выборочно записанные потенциалы, состояния и веса можно просматривать без запуска решателя.
- **«Копировать свойства»** в инспекторе позволяет применять настройки к нескольким элементам того же типа щелчками на топологии. Клавиша Esc завершает копирование.
- Экранная история состояний увеличена до 100 000 отсчётов и 4 млн значений. Окно сохранённых результатов использует свой бюджет данных.
- Исправлено падение Win32 при работе рядом с другим экземпляром программы.

Для просмотра экспорта держите `*_experiment.json`, `*_summary.json` и CSV с одним префиксом в одной папке. Вкладки показывают записанные величины и доступный интервал. Ряд внешнего тока в стандартном экспорте отсутствует.

Проверены штатный запуск, восемь целевых регрессий и просмотр большого сохранённого экспорта в Win32/DX11 без шагов решателя. Форматы Config JSON и NSCP и численный отпечаток совпадают с v2026.11.03.

В поставку входят GUI, CLI, вспомогательный `population`, инструкции, примеры и контрольные суммы. `BUILD_INFO.json` связывает файлы сборки с исходным коммитом.

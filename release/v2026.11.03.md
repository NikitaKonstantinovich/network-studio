# Network Studio — v2026.11.03

Переносимая сборка Windows x64. Скачайте **network-studio-v2026.11.03-windows-x64.zip**, распакуйте целиком и запустите **launch.cmd**. Готовые GUI/CLI не требуют CUDA, Python или Visual Studio.

- [Инструкция по установке](https://github.com/NikitaKonstantinovich/network-studio/blob/v2026.11.03/docs/INSTALL_RU.md).
- [Руководство GUI/CLI](https://github.com/NikitaKonstantinovich/network-studio/blob/v2026.11.03/docs/USER_GUIDE_RU.md).

## Изменения интерфейса

- Перетаскиваемые границы эксперимента, топологии, инспектора и нижних графиков; сворачивание графиков и сброс размеров.
- Компактные переключаемые панели для узких экранов, перенос кнопок и отдельное меню инструментов.
- Сворачиваемая статистика и выбор потоков при любой ширине окна; состояние сохраняется при изменении размеров в текущем запуске.
- Прозрачность связей по модулю текущего обученного веса; нейроны поверх линий; настройки топологии открываются кнопкой.
- Новые инструкции по установке, работе, наблюдению обучения, экспорту и продолжению опыта.

Сборка включает ранее разработанные методы интегрирования, checkpoint/resume, синаптические задержки, arrival/emission STDP, отдельные графики Windows, архивирование, профили анализа и нейроанимат. Размеры главных панелей сохраняются в текущем запуске; отдельные графики и их docking — в `.nsworkspace`.

## Совместимость и ограничения

Config JSON **10**, checkpoint **NSCP 8**, история NSH **2**, workspace **5**. Буфер недавней активности увеличен до 2 млн доставок и 2 млн спайков; численный отпечаток — `081d95233f86ea2b0cd5ca2a67dd4d4496d8608eb026ab348db19340b427e6c4`. Обычная загрузка checkpoint другой сборки отклоняется. Единственная отдельная миграция из `d43f543f…` описана в инструкции нейроанимата; исходные файлы не перезаписываются.

В архиве находятся GUI, основной CLI, специальный `population`, примеры, инструкции, `BUILD_INFO.json` и внутренние SHA-256. Исходники и тестовые программы в ZIP не входят; они доступны в теге релиза. Пользовательские опыты, лабораторные данные и контрольные точки в поставку не включены.

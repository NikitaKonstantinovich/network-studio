## Реализация

Добавлены единый список методов и проверка состава сети, GUI «Метод», CLI `--method`, JSON 10, метаданные результатов/архива и NSCP 8. Адаптивный RK4 оставлен по умолчанию. Один обычный RK4 и один синхронный Эйлер применяются к численной части; точные линейные переходы сохранены. Новые методы ограничены Ижикевичем без астроцитов, 1–500 мкс; HH/любой астроцит требуют адаптивного RK4, 1–50 мкс.

Все методы соблюдают прежние границы входа/шума/записи/доставок, kinetic_step_limit, этапы, контроллер и очередь команд. RK4 локализует порог по своему однократному переходу; Эйлер — по линейной траектории. Сбросы, ресурсы и STDP происходят в локализованное время; остаток шага продолжается. Одновременная группа использует прежние следы, новые следы добавляются после обновлений. [Полные соглашения](README_RU.md).

Физически недопустимая попытка уменьшает шаг вдвое с отдельным счётчиком; исчерпание попыток/разрешения часов останавливает расчёт. Обрезания значений, ослабления допусков, fast-math и скрытой смены метода нет. Нулевой счётчик отклонений у Эйлера/RK4 не означает оценённую нулевую ошибку: интерфейс сообщает «не применяется».

## Рекомендация и ограничения

- По умолчанию остаётся адаптивный RK4. Для исследования, чувствительного к индивидуальным спайкам и обучению этой сети, консервативная отправная точка — **25 мкс**, с дополнительной проверкой сходимости выбранной метрики. Длительный эталон с ещё меньшим шагом и серии seed здесь не выполнялись.
- **RK4, 100–500 мкс** подходит для быстрых предварительных коротких расчётов с последующей проверкой точности: на выполненных небольших примерах и первом всплеске он близок к эталону. Для точного 10-секундного поведения большой сети гарантии не получены; только из скорости выбирать его нельзя.
- **Эйлер** доступен для явного сравнения методов и учебных исследований. Для этой сети 50–500 мкс не рекомендуется как равноточная замена: нарушения заметны уже за 0,1 с. Даже нижняя граница 1 мкс не гарантирует принятый строгий бюджет V во всех FS-сценариях.
- Дополнительный контроль долгой траектории изменил вывод, который можно было бы сделать только по короткому тесту: максимальный шаг 500 мкс не даёт гарантию совпадения полного длительного эксперимента даже в адаптивном режиме. Длительные биологические сценарии, 150–400–1000 с, обучение/адаптация активного нейроанимата на большой сети и биологическая достоверность этим этапом не проверены.

Фактически измерено: 39 коротких прогонов по 0,1 с (183,96 с всего с I/O), три по 10 с (140,33 с с I/O), дополнительный 10-секундный контроль (368,445 с только вычисления), три профилированных по 0,1 с. Это **43,9 модельных секунды обычных больших измерительных прогонов**, плюс 0,3 с диагностической профилировки; не единый опыт такой длительности. Длительности штатных и отдельных процессных проверок приведены выше.

## Корректность и совместимость

- 1824 проверок сравнительного сценария: полные payload NSCP для всех режимов/повторов, бинарные состояния и все экспорты, перезапуск CLI с 8→12 потоками в каждой совместимой сборке. Отдельно эталонные сценарии задержек, triplet, HH/астроцита и общих/пространственных стимулов.
- Полная штатная серия: **44/44**, **408.48 с**; затем native smoke. См. `full-tests.log` и `validation/native_smoke`. Тест нормы сравнивает прежнюю скалярную формулу побитово на произвольных binary64, специальных значениях и неравных блоках; тест packed kernel сравнивает траекторию с общим вычислительным путём.
- Схема NSCP **5** и алгоритм **v4** сохранены, но build ID изменился. Старый файл не загружается новой сборкой; контроль не обходился. Межсборочное сравнение исключает только build ID и зависимую checksum, проверяя исходную целостность. Само по себе оно не разрешает межсборочное продолжение.
- 150–400 модельных секунд, поздняя стационарная активность, заполненные ограниченные журналы и несколько одновременно видимых окон не проверялись этой серией. Численное совпадение программ не доказывает биологической достоверности модели.

# Установка Network Studio

Инструкция для релиза `v2026.11.03`, Windows 10/11 x64. [Использование](USER_GUIDE_RU.md).

## Готовая программа

1. Откройте [релиз на GitHub](https://github.com/NikitaKonstantinovich/network-studio/releases/tag/v2026.11.03).
2. Скачайте **`network-studio-v2026.11.03-windows-x64.zip`** и **`SHA256SUMS.txt`**. Архивы «Source code» содержат исходники, а не готовые EXE.
3. Проверьте ZIP командой PowerShell и сравните результат со строкой архива в `SHA256SUMS.txt`:

   ```powershell
   Get-FileHash -Algorithm SHA256 .\network-studio-v2026.11.03-windows-x64.zip
   ```

4. Распакуйте ZIP целиком в доступную для записи папку, например `C:\Tools\NetworkStudio`. Не запускайте EXE внутри просмотра ZIP.
5. Откройте вложенную папку `network-studio-v2026.11.03-windows-x64` и запустите **`launch.cmd`** либо **`build\Release\network_studio.exe`**.

Вычисления выполняются на CPU. Интерфейс использует Direct3D 11 с программным резервным режимом WARP. CUDA Toolkit, видеокарта NVIDIA, Python и средства разработки для готовых GUI/CLI не нужны. Python нужен только для дополнительных скриптов. Программа переносимая, без установщика; удаление её папки удаляет программу. Собственные опыты и архивы хранятся отдельно.

Состав поставки:

```text
launch.cmd
build/Release/network_studio.exe             GUI
build/Release/network_studio_cli.exe         полный решатель CLI
build/Release/network_studio_population.exe  специальный агрегированный решатель
examples/                                   примеры конфигураций
neuroanimat/examples/                        примеры нейроанимата
docs/                                       инструкции
BUILD_INFO.json                             коммит, численный отпечаток, хэши EXE
CHECKSUMS.sha256                             хэши файлов внутри поставки
```

Основной CLI использует тот же решатель, что и GUI. `network_studio_population` предназначен для отдельных старых пакетных сценариев и поддерживает меньше возможностей, в частности только нулевые задержки.

## Первый запуск

Откройте PowerShell в распакованной папке:

```powershell
.\launch.cmd
.\build\Release\network_studio.exe .\examples\stdp_potentiation.json --plot-demo
.\build\Release\network_studio_cli.exe --help
```

Пути с пробелами заключайте в кавычки. Относительные пути команд разрешаются относительно текущего каталога PowerShell. `launch.cmd` находит EXE относительно собственного расположения. Конфигурации не требуют исходного диска `E:`.

В узком окне дополнительные действия открываются кнопкой **«Инструменты…»**. Заголовок **«Статистика расчёта и потоки»** при любой ширине открывает или скрывает счётчики, выбор потоков и частоту обновления GUI.

## Обновление и перенос

Новый релиз распаковывайте отдельно. Сохраните старые EXE и `BUILD_INFO.json` вместе с важными checkpoint. JSON, checkpoint, рабочее пространство и дисковая история имеют разное назначение — см. [руководство](USER_GUIDE_RU.md#сохранение-и-продолжение).

Последнее пространство отдельных графиков автоматически сохраняется в `%LOCALAPPDATA%\NetworkStudio\plots.nsworkspace`. Для другого рабочего пространства используйте `--workspace PATH` или меню сохранения пространства. Размеры главных панелей и свёрнутость статистики сохраняются только в текущем запуске.

У релиза схема **NSCP 8** и численный отпечаток **`081d95233f86ea2b0cd5ca2a67dd4d4496d8608eb026ab348db19340b427e6c4`**. Обычный загрузчик строго проверяет отпечаток. Несовместимые checkpoint открывайте соответствующим старым EXE. Единственная отдельная миграция `d43f543f… → 081d9523…` описана в [документации нейроанимата](../neuroanimat/README_RU.md); она применима только к этой проверенной паре сборок.

## Сборка из исходников

Установите Git, CMake ≥3.20, Visual Studio 2022 или Build Tools с C++ x64 и Windows SDK. Для полного набора проверок установите Python ≥3.10 и сделайте его доступным CMake; без него три Python-проверки пропускаются с предупреждением. Библиотеки C++ включены в `vendor/`; CUDA не требуется.

```powershell
git clone --branch v2026.11.03 https://github.com/NikitaKonstantinovich/network-studio.git
cd network-studio
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Test -Smoke
.\launch.cmd
```

Скрипт сам выбирает SDK, инициализирует MSVC и собирает Release в `build\Release`. `-Test` запускает штатные тесты, `-Smoke` — реальный GUI. `-SmokeOutput PATH` задаёт отдельный каталог результатов. Не переносите чужой кэш `build\native` в новую копию исходников.

## Если возникла проблема

- Проверьте, что распакован весь ZIP и выбран Windows x64 EXE.
- При предупреждении Windows о происхождении файла проверьте адрес релиза и SHA-256. Эта сборка не подписана сертификатом издателя.
- Ошибка несовместимости `.nscp` — проверка воспроизводимости; используйте EXE, создавший файл.
- Для большой истории до нового запуска выберите меньше записываемых объектов, увеличьте интервал записи или настройте ограниченную память и архив на диске.
- Для потерянного за пределами экрана графика: **«Рабочее пространство… → Сбросить расположение окон»**. Для главных панелей: **«Сбросить размеры панелей»**.

Программа — исследовательский инструмент. Программные и численные тесты не устанавливают биологическую достоверность моделей.

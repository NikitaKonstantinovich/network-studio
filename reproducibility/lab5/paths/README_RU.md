# ЛР5 по пособию / четвёртая выполненная работа: прямой и обходной пути

Выполнены **36 настоящих CLI-прогонов** исходной сборкой: три топологии × десять согласованных seed 0–9 при Noise=3, три контроля без шума и три проверки половинного шага при seed=0. Все прогоны завершили 5 с. Проверены полные конфигурации schema 4, конечное время, число шагов, конечность CSV, соответствие журналов спайков сводкам, диапазоны весов и независимый пересчёт мультипликативного парного STDP по всем предыдущим парам. Максимальное расхождение конечного веса с пересчётом — `4.17e−17`.

Протокол: RS `.02/.2/−65/8`, начальные `V=−65,u=−13`, только N1 получает `25×3 мс`, 10 Гц, первый импульс 50–53 мс. TM: `A=20,U=.5,tau_rec=.05,tau_syn=.01,tau_fac=1` с; все начальные веса `.1`. Мультипликативное парное STDP: `A+=A−=.001`, `tau+=tau−=.01` с, границы 0..1. Глобальный независимый гауссов шум σ=3 удерживается 1 мс; индивидуальный шум выключен. Основной шаг 25 мкс, запись каждые 0.1 мс. N1/N2/N3 соответствуют №5/№6/№7 исходного отчёта.

| Схема | Спайки N1 / N2 / N3 за 5 с, диапазоны десяти seed | Конечные веса: среднее [min; max] |
|---|---|---|
| N1→N2 | 70–79 / 1–6 | 1→2: .10083452 [.09998846; .10180367] |
| N1→N2→N3 | 70–79 / 1–6 / 0–4 | 1→2: как выше; 2→3: .09999498 [.09994429; .10000551] |
| Цепочка + N1→N3 | 70–79 / 1–6 / 1–6 | 1→2: как выше; 2→3: .10011818 [.09996394; .10064128]; 1→3: .10144372 [.10032331; .10390886] |

Прямая связь усилилась во всех десяти seed: от +0.3233% до +3.9089%, в среднем +1.4437%. Это ниже единичного значения NeuroNet `.106812` (+6.812%). На согласованных seed добавление прямой связи не меняет спайки N1 и N2, но повышает среднее число спайков N3 с .9 до 3.5. Вес обходной связи 2→3 может почти не меняться, уменьшаться или увеличиваться; устойчивое ослабление обходного пути не установлено.

**Без шума** во всех трёх схемах получено 75 спайков N1 и ноль у остальных; каждый вес остался ровно `.1`. Максимум записанного V остальных нейронов за весь опыт — −65 мВ, то есть начальное значение. Нет постсинаптических событий, необходимых для изменения веса: этот контроль не демонстрирует конкуренцию двух активных путей. В шумной серии посредник уже спайкует, но наличие событий само по себе ещё не устанавливает причинность каждого спайка N3: для полного доказательства нужны дополнительные вмешательства и анализ времени прохождения.

При половинном шаге 12.5 мкс (seed=0) числа спайков сохранились: `[74,6]`, `[74,6,4]`, `[74,6,6]`. Наибольшая разность конечных весов — `3.02e−6` для сети с прямой связью. Максимальное отличие попарно сопоставленных времён спайков N1 — 0.3875 мс; у постсинаптических нейронов — 0.0125 мс. Поэтому нельзя приписывать всей траектории ошибку «не больше одного шага» только по способу фиксации отдельного порога.

Исходный [отчёт NeuroNet, задание 3](../../../../../../labs/lab4_report/Отчёт_ЛР4.md) подтверждает Noise=3, веса двух нейронов/цепочки `.1` и прямую связь `.106812`. Короткие кадры показывают подпороговые ответы без зарегистрированных пиков в двух первых схемах; у последней схемы показаны только конечные веса после открытия пустого окна истории. Полного журнала событий нет. Поэтому различия нашей шумной серии с этим отчётом нельзя трактовать как строгую ошибку одного симулятора.

Найденные [исходные `.net` и временные опоры](../sources/README_RU.md) уточняют интервал между сохранениями: для двух нейронов 11.675→17.775 с, то есть 6.100 с; для сети с прямой связью 19.895→32.420 с, то есть 12.525 с. Это конкретнее первоначального плана «около 5 с», но не восстанавливает весь порядок включения обучения между снимками. Отдельный [контроль длительности](../duration/findings.json) повторяет эти интервалы на новых начальных состояниях: при 12.525 с прямой вес имеет среднее `.10334371`, диапазон `.10193275–.10534530`. Он также не достигает исходного `.106812` на проверенных seed; это ограниченный перебор, не доказательство недостижимости. Цепочка на 12.525 с служит сравнением топологии, а не восстановленной длительностью оригинала.

Неизвестны реализация шума и seed NeuroNet, полный порядок обучения и изменения состояний между сохранёнными снимками. Часть начальных состояний теперь извлечена из `.net`; в этой серии они не импортировались. В NeuroNet использован Step=.500 и показана Sp. Velocity=.050; здесь RK4 25 мкс и нет проводящих задержек. Каждый новый CLI-проход автономно стартует из стандартного состояния с нулевыми следами STDP и восстановленным TM-ресурсом. Сброс одних весов в продолжавшемся исходном опыте не гарантирует такого же состояния. Номер seed сопоставляет нейроны между нашими топологиями, а не восстанавливает неизвестную реализацию шума оригинала.

Все конфигурации находятся в [configs](configs/), индивидуальные события, sampled-максимумы V, веса, разбросы, сравнение шагов и SHA-256 — в [findings.json](findings.json). Максимумы V имеют дискретность записи 0.1 мс и могут не достигать порога, поскольку сброс выполняется до записи; число спайков определяется полным журналом solver-событий. Общая продолжительность выполнения самих CLI была 29.15 с; обработка CSV добавляет время.

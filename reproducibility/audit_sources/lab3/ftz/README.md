# Диагностика FTZ + DAZ для аудита ЛР3

Этот отдельный CLI перед входом в неизменённый `cli.cpp` устанавливает биты FTZ (15) и DAZ (6) регистра MXCSR. Субнормальные результаты арифметики и входные операнды обрабатываются как нули. Обычные числа не получают намеренного округления или порога; у затухающего состояния, однако, может остаться очень малый хвост, если его приращение стало субнормальным. Поэтому сравнение проверяет **все** численные различия, включая нормальные малые хвосты.

Это отдельная численная конвенция и контроль производительности, а не изменение штатной программы. Он связан с тем же готовым `build/native/network_core.lib`; уравнения, шаг, исходники и производственный `build/Release/network_studio_cli.exe` не меняются. Использованы MSVC 19.44.35217.0, x64 Release, `/O2 /Ob2 /MT` (тот же компилятор и библиотека, что в штатной сборке; здесь генератор CMake Visual Studio).

Из каталога `standalone/network_studio`, после обычной сборки:

```powershell
cmake -S verification/repro_labs_20261012/lab3/ftz -B verification/repro_labs_20261012/lab3/ftz/build -G "Visual Studio 17 2022" -A x64
cmake --build verification/repro_labs_20261012/lab3/ftz/build --config Release --parallel 2
python verification/repro_labs_20261012/lab3/ftz_audit.py
```

Перед запуском должны существовать четыре входа `lab3/configs/network_benchmark.json` и `network_net1_{0p1,1,100}Hz.json` **внутри каталога аудита**, созданные `network_audit.py`. Под `lab3` в этом предложении понимается `verification/repro_labs_20261012/lab3`, а не исходный пакет лабораторной. Скрипт запускает четыре опыта параллельно. Для повторного анализа без расчёта:

```powershell
python verification/repro_labs_20261012/lab3/ftz_audit.py --skip-run
```

Python использует только стандартную библиотеку; в аудите применён bundled Python 3.12. Результаты имеют префикс `raw/ftz_`; `ftz_findings.json` сохраняет отдельные SHA-256 обоих исполняемых файлов, подключённой библиотеки, исходников, launcher и скрипта. Этот файл не заменяет `network_findings.json` штатных опытов.

Сравнение включает порядок/время всех экспортированных спайков, веса, каждую строку всех выборочно записанных нейронных и синаптических состояний. Приведены побайтовое равенство, число численных различий и их максимумы отдельно для нормальных и субнормальных значений. Совпадение только короткого контроля не доказывает совпадения длительных траекторий; для завершённых штатных 30-секундных опытов проводится полное сравнение.

# Повтор лабораторных 1–4 и проверка ускорения

Серия начата 13 октября и завершена 14 октября 2026 года. Ветка: `audit/labs-1-4-20261013`; исходный коммит до ускорения: `d8ddfcb88c9d66d387c9dd88c9888809f223b502`. ЛР4 здесь означает четвёртую выполненную работу — ЛР5 методички, посвящённую STDP.

## Заключение

Исправленный интегратор рассчитывает заданную модель точнее. Это подтверждено независимым решателем DOP853 для отдельных нейронов, уточнением шага, точной TM-рекуррентностью и независимым пересчётом весов по событиям. Ускорение, добавленное в этой ветке, сохраняет результаты в проверенных сценариях побайтово.

Основные качественные результаты лабораторных сохранились, но отдельные численные результаты изменились существенно. Более точное решение собственных уравнений не означает автоматического улучшения совпадения с NeuroNet или подтверждения биологической достоверности.

| Работа | Что изменилось относительно прежнего Studio |
|---|---|
| ЛР1 | Режимы покоя, автоколебаний и постоянной стимуляции сохранились. Сильно уменьшилась ошибка времени спайков; в отдельных шумовых опытах изменилось их количество. |
| ЛР2 | Классификация циркуляции всех проверенных колец сохранилась. В двух 100-секундных популяционных опытах число спайков выросло на 0,45–0,54%. |
| ЛР3 | При 0,1 Гц полная сеть дала 7438 спайков за 30 с вместо 4864. Первый всплеск содержит 2495 событий на шагах 25 / 12,5 / 6,25 мкс вместо архивных 1620. При 100 Гц установившаяся активность сохранилась: 5 активных нейронов и 5000 спайков в окне 10–30 с. |
| ЛР4 | Направления обучения в 14 основных протоколах сохранились. В опыте «пост–пре, 10 Гц» конечный вес изменился с 0,00077503 до 0,000937317 (+20,94%), оставаясь сильно ослабленным. |

Расхождения с NeuroNet сохраняются, в частности для TM-кольца из 10 нейронов и ответов на импульсы 30×3 мс. Три сетевых опыта ЛР3 повторены как отдельные запуски по 30 с; они не воспроизводят историю ручного сеанса NeuroNet с последовательным переключением частоты без сброса. Полные 30-секундные сети не сверялись с независимым адаптивным решателем всей сети: уточнение шага проверено на её начальном участке и полном первом всплеске.

## Что ускорено

Коэффициенты одинаковых точных линейных переходов вычисляются повторно только при изменении параметров. В сетях без астроцитов поиск порога использует собственные координаты нейрона и его входящие синаптические хвосты с прежним порядком суммирования. Линейные значения общих стадий RK используются повторно, а неиспользуемые линейные производные пропускаются. Полное принятое состояние, адаптивная норма ошибки, границы входов, локализация спайков и порядок обучения сохранены. С астроцитами остаётся общий путь интегрирования и поиска порога.

Входящие списки, рабочие буферы и функции пересоздаются при восстановлении Simulator; нового сериализуемого состояния не добавлено. Однако строгий отпечаток сборки checkpoint изменился: прежние `.nscp` следует открывать той сборкой, которая их сохранила. Побайтовое сравнение в аудите не обходит защиту загрузчика.

Замеры скорости находятся в отчёте. Они сделаны при параллельной нагрузке и не являются универсальной гарантией ускорения для любых сетей.

## Сборка и повторение

Из корня репозитория, Windows x64, MSVC / Windows SDK / CMake:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Test -Smoke
.\launch.cmd
```

Эта команда проверяет текущие исходники без старого локального архива лабораторных. Для пакетного повторения сравнений дополнительно нужны Python, NumPy, SciPy, Matplotlib и сохранённые старые конфигурации/CSV из `lab1`, `lab2`, `lab3`, `reproducibility/lab5` и `verification/repro_labs_20261012`. Полный архив не входит в Git. Одного клона достаточно для сборки и штатных тестов, но недостаточно для всех исторических сравнений.

Основные исполнители принимают новый каталог результатов:

```powershell
python -B reproducibility/recheck_20261013/replay.py --output verification/labs_new --workers 4
python -B reproducibility/recheck_20261013/extras.py --output verification/labs_new
python -B reproducibility/recheck_20261013/bridge.py --output verification/labs_new
python -B reproducibility/recheck_20261013/independent.py --output verification/labs_new
python -B reproducibility/recheck_20261013/burst_convergence.py --output verification/labs_new
python -B reproducibility/recheck_20261013/interface_controls.py --output verification/labs_new
python -B reproducibility/recheck_20261013/integrity.py --output verification/labs_new
python -B reproducibility/recheck_20261013/analyze.py --output verification/labs_new
```

Выполняйте команды последовательно и проверяйте код завершения каждого процесса. Выберите отсутствующий каталог вместо `verification/labs_new`; не пересобирайте исполняемые файлы и не меняйте входы во время серии. В исходной среде зависимости Python находятся в `E:/asp/26_27/tmp/python_deps` и подключаются через `PYTHONPATH`.

`optimization.py` сравнивает две сохранённые сборки (`--old`, `--new`, `--output`); `validate_compact.py` повторно проверяет окончательную оптимизацию на замороженном наборе. `compare_optimization_archive.py` сверяет завершённые архивные повторы. Для этих проверок нужны исходные бинарные файлы и их результаты, которых нет в Git.

`plots.py` и `report.py` записывают итоговые материалы рядом со своими исходниками. Для новой серии сначала создайте отдельную копию каталога под `reproducibility/`, чтобы не перезаписать этот отчёт. `report.py` / `finalize.py` проверяют полный набор манифестов именно этой серии, включая доказательства ускорения; это не универсальные генераторы отчёта для произвольной сети. `queue_barrier.py`, `complete_queued_benchmarks.py` и `population_parallel.py` сохранены как история промежуточной организации вычислений и не нужны для приведённой последовательности.

Сырые результаты завершённой серии: `verification/labs_1_4_20261014_compact`. Прежние результаты сохранены отдельно. Вспомогательный счётчик прогресса был восстановлен после временной ошибки атомарного переименования Windows; все нативные результаты проверены по хэшам, без повторного расчёта. Подробности сохранены в полном отчёте и манифесте.

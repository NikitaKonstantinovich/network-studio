## Что реализовано

- Версионированный пакет: Config/необязательный самостоятельный NSCP, исходные и
  нормализованные принятые команды, получатели, профиль/интервал, seed шума и
  метаданные генерации, CLI/runner, build/алгоритм/окружение/threads, SHA-256.
- Проверка без шагов модели через штатные C++ загрузчики. Контроль SHA до и после
  каждого запуска, запрет перезаписи результатов, проверки протокола, будущего
  покрытия и фактического покрытия/предыстории после расчёта.
- Отдельный фон на seed; каждая ветвь и повтор стартуют в новом процессе из
  одного неизменяемого checkpoint. Старые ветви не используются как новые входы.
- Согласованный отчёт по принятым командам, фактическим импульсам, спайкам, полным
  конечным весам и входным условиям. Для повторов требуется точное совпадение,
  включая нормализованный NSCP со служебным состоянием интегратора. Допуски
  показываются отдельно; отсутствующее событие нельзя скрыть допуском времени.
- Значения отдельных запусков и разброс по seed; повтор не увеличивает N серии.
  Полные архивные события читаются потоком, без загрузки всей истории состояний.
- Готовые сценарии короткой проверки и лабораторного опыта 150 → 400 с.

Новые файлы: `package_cli.cpp`, `experiment_package/package.py`,
`make_scenario.py`, `prepare.ps1`, `tests.py`; документация — README этого каталога
и корня проекта. Уравнения, dt, допуски, суммирование, события/STDP не менялись.

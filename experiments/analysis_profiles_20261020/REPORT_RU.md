## Ограничения и совместимость

- Достаточность предыстории проверяется консервативно. Длинная непрерывная активность после усечения журнала может оставить анализ неподтверждённым; для полного результата нужна более глубокая история.
- Экран удерживает ограниченный журнал, поэтому экспорт вычислителя может иметь больше данных. Сравнение требует одинакового полного покрытия, а не только имени профиля.
- Профили задают индексы нейронов/ID источника; соответствие объектов разных сетей пользователь проверяет содержательно. Проверка метаданных не доказывает тождество научных условий.
- Офлайн-режим опирается на доступность, заявленную штатным `_summary.json`; он не восстанавливает удалённые события и не является универсальным CSV-импортом. Все использованные входные файлы фиксируются SHA-256.
- Workspace 5 обратно читает 1–4; научный JSON остаётся 7, checkpoint — 4. **Fingerprint checkpoint изменился** (код анализа/I/O входит в прежнюю строгую сигнатуру). Старые `.nscp` требуют исходную сборку. Совместимость не обходилась; лабораторные ветви проанализированы из CSV/JSON.
- Новые профили и интервалы хранятся в workspace, а не в checkpoint. Конфигурационные `AnalysisSettings` сохраняют прежнюю семантику.
